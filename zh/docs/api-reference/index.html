API 参考

Mutative API 的参数、返回值及示例。

create()

根据更新函数对基础状态草稿的修改，生成下一个状态。

apply()

将补丁应用到状态，返回下一个状态，或原地修改状态。

makeCreator()

创建带默认选项的 create() 函数。

current()

获取草稿当前值的快照，返回不含代理的普通对象。

original()

获取创建草稿时的原值，不包含更新函数的修改。

rawReturn()

原样返回不含草稿的值并跳过搜索，或将状态设为 undefined。

unsafe()

在严格模式下读取未创建草稿的值。

isDraftable()

检查 Mutative 是否能为值创建草稿，可指定 mark。

isDraft()

检查一个值是否为草稿。

markSimpleObject()

允许无原型对象和跨 realm 普通对象创建草稿的标记。

类型转换

castDraft()、castImmutable() 和 castMutable() 改变 TypeScript 类型，并原样返回值。
