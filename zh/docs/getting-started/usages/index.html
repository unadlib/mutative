常见用法

使用 create() 对对象、数组、Map 和 Set 进行常见的不可变更新。

使用 create() 创建新状态

create(baseState, recipe, options?) 为基础状态创建草稿，并将它传给更新函数。更新函数使用普通 JavaScript 修改草稿，create() 返回下一个状态：复制已修改的对象，与基础状态共享其余对象。基础状态保持不变。选项及其他调用方式见 create()。
