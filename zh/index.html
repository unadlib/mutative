功能

不可变更新所需的功能

为多种数据结构提供草稿，按需开启补丁、冻结、标记与严格模式。

用可变写法完成不可变更新

通过修改草稿，对对象、数组、Set 和 Map 进行不可变更新。

高性能

默认配置下性能约为 Immer 的 6.6 倍；在含数千个键的对象上，也快于手写展开语法。

可选冻结

默认不冻结不可变数据，需要时可开启自动冻结。

JSON Patch

每次更新可生成正向与逆向补丁，并支持 JSON Patch 格式。

自定义浅拷贝

通过自定义浅拷贝支持类实例等更多不可变数据类型。

非侵入式标记

无需改变结构，即可标记不可变与可变数据。

严格模式

显式读取未创建草稿的数据，避免无意中原地修改。

Reducer 支持

producer 可作为 reducer，配合 Redux 等不可变状态库使用。
