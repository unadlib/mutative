---
title: Typescript
---

Mutative support is built into the typescript types. You can use the `Draft<T>` and `Immutable<T>` types to annotate your code.

Mutative's types support TypeScript 5.0 and later; the package checks compile them with TypeScript 5.0.

## Using TypeScript

- `castDraft()`
- `castImmutable()`
- `castMutable()`
- `Draft<T>`
- `Immutable<T>`
- `Patches`
- `Patch`
- `Options<O, F>`
