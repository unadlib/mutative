Migration from Immer to Mutative

Replace Immer's APIs with their Mutative counterparts, and check the defaults that differ.

Most code moves from Immer to Mutative by renaming functions: in both libraries a recipe changes a draft, and the next state shares every part that the recipe left unchanged. Comparison with Immer maps every Immer API to Mutative and lists the behaviors that differ.

mutative-compat wraps Mutative in Immer's API, for a quick switch before you migrate the calls themselves.

Checklist

  1. Replace produce() with create(), produceWithPatches() with create() and enablePatches: true, applyPatches() with apply(), and nothing with rawReturn(undefined). current(), original(), isDraft(), isDraftable(), castDraft() and castImmutable() keep their names.
  2. Remove the enableMapSet(), enablePatches() and enableArrayMethods() calls: Mutative supports Maps, Sets and patches without them, and runs array methods natively.
  3. Decide about freezing. Immer freezes the next state by default, and Mutative does not. Code that relies on frozen state, for example to catch accidental mutations, needs enableAutoFreeze: true.
  4. Replace the global configuration of setAutoFreeze() and new Immer() with options per call, or with defaults that makeCreator() sets.
  5. Replace [immerable] = true on classes with the mark option.

A patch listener passed to produce() becomes the same option: read the patches from the result of create(). The patches of both libraries differ for arrays that get shorter, which Mutative records as a replace of the length by default, and for objects changed in a Set; enablePatches: { arrayLengthAssignment: false } makes Mutative remove each index, as Immer does. Async recipes

Immer 11 does not support async recipes: one that changes the draft before its first await throws, because the returned Promise counts as a new value, and one that changes it later writes to a revoked draft. TypeScript

Draft<T>, Immutable<T> and Patch are exported by both libraries, and Mutative adds Patches, the type of a list of patches, and castMutable(). Mutative infers the result type of create() from its options, such as the tuple of patches with enablePatches: true; see TypeScript.
