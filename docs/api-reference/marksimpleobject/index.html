API Reference

markSimpleObject()

A mark that drafts objects without a prototype and plain objects of other realms.

markSimpleObject is a mark that makes simple objects draftable: plain objects, objects without a prototype, such as those of Object.create(null), and plain objects of other realms, such as same-origin iframes or vm contexts, whose prototype is that realm's Object.prototype. Without it, Mutative drafts only plain objects of its own realm, and create() throws for a base state of the other kinds.

Usage

Pass it as the mark option, of a call or of makeCreator():

It returns 'immutable' for simple objects and nothing for other values, which Mutative then drafts as usual, so it combines with other marks in an array, as in mark: [markSimpleObject, markClasses]. Like any immutable mark, it works with patches and auto-freeze.
