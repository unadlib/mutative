Getting Started

Usages

Common immutable updates of objects, arrays, Maps and Sets with create().

Use create() to create a new state

create(baseState, recipe, options?) drafts the base state and passes the draft to the recipe. The recipe changes the draft with ordinary JavaScript, and create() returns the next state, which copies the objects that the recipe changed and shares all the others with the base state. The base state does not change. See create() for its options and its other forms.

The examples below change a draft as plain JavaScript would change the state itself.

Maps and Sets

Values read from a Map or Set draft are drafts too, while Map keys are used as they are. See the FAQ for iterating over Map drafts, drafts as Map keys and the Set methods of ES2025.
