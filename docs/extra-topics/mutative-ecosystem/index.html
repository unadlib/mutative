Mutative Ecosystem

Libraries built on Mutative for React, Zustand, Jotai, XState, Yjs, undo and redo, and more.

These libraries use Mutative for the immutable updates of other tools. Install each one together with mutative, and see its repository for its full API.

React

  • use-mutative - A 2-6x faster alternative to useState with spread operation, with useMutative() and useMutativeReducer(); see Using Mutative with React.
  • use-travel - A React hook for state time travel with undo, redo, reset and archive functionalities.
  • reactant - A framework for building React applications, with Mutative for immutable updates.

Undo and redo

travels is a framework-agnostic undo and redo core that keeps the history of a state as Mutative patches, with history limits, archives and persistence:

use-travel and zustand-travel bring it to React and Zustand. To build undo and redo on patches yourself, see Patches.

Other libraries

  • mutative-compat - Mutative wrapper with full Immer API compatibility.
  • mutability - A JavaScript library for transactional mutable updates, which changes the state in place and returns patches.
  • usm - A concise and flexible state model for Redux, MobX, Vuex, Pinia and more.
